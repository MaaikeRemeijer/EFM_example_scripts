# Supplementary files — *Entangled stoichiometric objectives shape microbial catabolism*

This repository contains the supplementary files accompanying the preprint:

> *Net conversion calculations of catabolic pathways*. Preprint.
> DOI: [DOI PLACEHOLDER]

The files provide the linear algebra method, the elementary flux mode (EFM) calculations, and the Max-Min Driving Force (MDF) analysis used in the manuscript. Excel files contain the stoichiometric data; the corresponding Python files reproduce the calculations and figures.

## Contents

| File | Description |
| --- | --- |
| S1 | Linear algebra method (Python) |
| S2 | Excel file, 1 EFM |
| S3 | Python file, 1 EFM |
| S4 | Excel file, 8 EFMs |
| S5 | Python file, 8 EFMs |
| S6 | Excel file, 24 EFMs |
| S7 | Python file, 24 EFMs |
| S8 | MDF analysis (Python) |
